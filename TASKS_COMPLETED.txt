  关键发现
════════════════════════════════════════════════════════════════════════════════

1. VLM Grounding 能力稳健
   - 跨帧 ID 连续率 100% (无断裂)
   - 能区分 car/motorcycle/person 等类别
   - 可进行粗粒度深度估算 (近/中/远)

2. 对消融实验的解释
   - No-YOLO (C3) 胜过基线 +1.6% F1
   - 原因: 去除 YOLO metadata 文本消除了 VLM 幻觉
   - VLM 纯视觉推理比 metadata 受限更准确

3. 技术亮点
   - 多分辨率支持 (4096x2160)
   - 双向坐标转换 (像素 ↔ 归一化)
   - 二阶段错误恢复 (JSON 解析失败自动降级)

4. 最佳实践建议
   ✓ 保留 MOG2 + SigLIP 预处理
   ✓ 移除 YOLO metadata 文本注入
   ✓ 让 VLM 基于纯视觉做判断
   ✓ YOLO 用于可视化诊断，不用于 VLM 输入
